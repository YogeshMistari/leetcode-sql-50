A structured collection of my **LeetCode SQL solutions, explanations, and interview preparation notes**.

The goal of this repository is to strengthen SQL problem-solving skills through practical problems and prepare for **SQL / Oracle SQL / PL/SQL Developer interviews**.

---

## 🎯 Objectives

- Solve the **LeetCode SQL 50** problems.
- Improve SQL query-writing and problem-solving skills.
- Strengthen SQL fundamentals and advanced concepts.
- Practice real-world SQL interview problems.
- Build a strong understanding of:
  - JOINs
  - Subqueries
  - CTEs
  - Window Functions
  - Aggregations
  - GROUP BY / HAVING
  - CASE expressions
  - String Functions
  - Date Functions
  - NULL handling
  - Ranking and analytical queries
- Maintain a personal SQL interview reference.
- Strengthen concepts useful for **Oracle SQL and PL/SQL development**.
